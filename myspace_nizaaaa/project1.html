Project Overview

This website serves as my personal digital portfolio, showcasing my academic journey, skills, and achievements in an interactive way. It includes modules for staff and admin, with easy navigation and responsive design.

  • Responsive web design using HTML, CSS, JS
  • Interactive animations and scroll effects
  • Organized sections for easy navigation
  • Clean typography and color palette

Project Objectives

  • Centralize vehicle booking requests and records
  • Simplify staff application and admin approval process
  • Provide real-time status updates
  • Maintain history for reporting
  • Offer a user-friendly, responsive interface

Project Development Timeline

Planning

Understanding current workflow, identifying issues, and defining project requirements and objectives.

Design & UI/UX

Wireframes, color schemes, fonts, and responsive layouts designed for clarity and usability for staff and admin modules.

Development

Implemented core functionalities, secure login, request forms, dashboards, assignment features, and database integration.

Testing & Launch

Thorough testing, bug fixing, optimization, and deployment with staff training for smooth operational use.

Lesson Learned

Through this project, I improved my skills in HTML, CSS, JavaScript, and responsive web design. I learned to create interactive user interfaces and implement a practical workflow for staff and admin modules.

Collaboration and planning were essential in understanding user requirements and translating them into functional design. I also gained experience in problem-solving, debugging, and deploying a fully functional system.

Overall, this project strengthened my ability to combine design and development while keeping user experience at the forefront.
